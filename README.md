# 玄览 · 术数聚合平台

> 一次输入，八大体系并排推演；内核严肃、外壳科普。
> 一个面向「玄学/术数」的聚合体验与科普平台——把八字、紫微、奇门、六壬、小六壬、梅花易数、西洋占星、塔罗放在同一张桌上，让它们互相印证、也互相制衡。

---

## 为什么做这个

市面上算命类 App（问真八字、灵机、测测等）几乎都是**单体系**、**黑盒**、**不可复现**，而且为了「准」的观感往往夸大有效性。

玄览想解决三件事：

1. **单体系无法交叉验证** —— 你只信一套，就永远不知道另一套会不会反对你。玄览让八家同台，用**共识度**告诉你「它们到底想到一块没有」。
2. **黑盒不敢信** —— 所有计算都在**纯函数内核**里，零网络、零随机数隐式调用，同一输入永远同一输出，可快照、可审计、可测试。
3. **不可复现就没法复盘** —— 内核不调用 `Date.now()` / `Math.random()`，时间与时辰由调用方注入；卜卦类体系的「随机种子」由**问题文本 + 起卦时刻**哈希派生，可溯源。

---

## 三个关键设计决策

### 1. 内核严肃，外壳科普
内核（算法层）严格按古籍规则确定性计算，工程上可验证；外壳（前端）用科普折叠层讲清楚「源流 / 流派分歧 / 诚实边界」，**绝不把娱乐包装成预测**。

### 2. 决策轴模型（本项目最值钱的建模思路）
八大体系术语体系完全不同（五行生克 / 星辰宫位 / 卦象 / 牌意），无法直接相加。玄览把每个体系的「答案」投影到**六条统一的决策轴**上：

| 轴 | 含义 |
| --- | --- |
| 行动 | 宜动 / 宜静 |
| 时机 | 宜进 / 宜守 |
| 人际 | 宜结盟 / 宜独处 |
| 进取 | 宜攻 / 宜稳 |
| 变化 | 宜变 / 宜不变 |
| 吉凶 | 整体倾向 |

每条轴的取值 ∈ [-2, 2]，带该体系的**置信度权重**。聚合层做：
- **加权平均**（置信度加权）→ 各轴主调
- **一致率**（同方向占比）→ 体系们有多齐心
- **分歧体系**（|得分−均值|>1）→ 谁在唱反调

> 这是把「异质多专家系统」收敛到一个可比较空间的标准做法，也是本项目的工程/建模核心。

### 3. 可复现优先
内核纯函数化 + 种子注入，使得「同一问题、同一时刻」永远得到同一结果；历史记录存**完整结果**而非种子，算法演进后老记录也不会变形。

## 功能

- **八大体系并排推演**：八字 · 紫微 · 奇门 · 六壬 · 小六壬 · 梅花易数 · 西洋占星 · 塔罗（含各自流派开关：奇门置闰/拆补、紫微中州派、塔罗牌阵等）
- **共识度仪表盘**：6 轴加权均值 + 一致率 + 分歧体系高亮
- **综合解读报告**：把八家结论翻译成人话长文，可一键复制 / 导出
- **术语词典**：卡片内硬核词点击看白话解释
- **历史记录 + 导出**：排盘自动入库，可回放 / 导出 Markdown / JSON
- **入场页 + 项目故事页**：仪式感太极八卦入口；项目故事页讲清思考、迭代与能力范围

## 架构

```
packages/core/            纯函数算法内核（禁 IO / 禁 Date.now / 禁 Math.random）
  ├─ adapters/            八大体系的适配层（mingyu-core + iztro）
  ├─ interpretation.ts    确定性「解释层」（五行旺衰 / 体用生克 / 吉凶 / 应期…）
  ├─ consensus.ts         决策轴聚合（加权平均 + 一致率 + 分歧）
  ├─ report.ts            综合解读报告（模板化叙事，零随机、零 AI）
  └─ test/                内核回归（30 项）
src/                      Vite + React + TS 前端
  ├─ Landing.tsx          太极八卦入场页
  ├─ App.tsx              主应用（表单 / 结果墙 / 三视图路由）
  ├─ ConsensusDashboard / SynthesisReport / Interpretation / HistoryPanel
  └─ renderers.tsx        八大体系专属渲染器
```

数据流：`出生信息 + 问题 → 内核并行计算 → 各体系 assertions 投影到决策轴 → 共识聚合 → 综合报告 + 各卡解读`。

## 诚实边界（也是产品克制）

- 以上为各体系按古籍规则的**确定性计算**，不是概率预测，其有效性在科学上尚无共识。
- **命盘类**（八字、紫微、西洋占星）反映长期趋势，由出生信息决定，不随你此刻的问题改变。
- **卜卦类**（六壬、奇门、梅花、小六壬、塔罗）针对你此问的当下信号——换时间 / 换问题，卦象自然不同。
- 涉及人生、医疗、法律、财务的决定，请咨询持证专业人士。
