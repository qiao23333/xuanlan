# 玄览 · 术数聚合平台

> 一次输入，八大体系并排推演；
> 一个面向「玄学/术数」的聚合体验与科普平台——把八字、紫微、奇门、大六壬、小六壬、梅花易数、西洋占星、塔罗放在同一张桌上，让它们互相印证、也互相制衡。

**和「直接问 AI」的区别**：AI 给你一段不可验证的话；玄览给八个按古籍规则确定性计算的体系、六条决策轴上的量化共识、谁在唱反调的显式标记，以及一个对方打开就能逐字复现的只读链接。零后端、零网络请求、全本地计算。

## 为什么做这个

市面上算命类 App（问真八字、灵机、测测等）几乎都是**单体系**、**黑盒**、**不可复现**，而且为了「准」的观感往往夸大有效性。

玄览想解决三件事：

1. **单体系无法交叉验证** —— 你只信一套，就永远不知道另一套会不会反对你。玄览让八家同台，用**共识度**告诉你「它们到底想到一块没有」。
2. **黑盒不敢信** —— 所有计算都在**纯函数内核**里，零网络、零随机数隐式调用，同一输入永远同一输出，可快照、可审计、可测试。
3. **不可复现就没法复盘** —— 内核不调用 `Date.now()` / `Math.random()`，时间与时辰由调用方注入；卜卦类体系的「随机种子」由**问题文本 + 起卦时刻**哈希派生，可溯源。

## 三个关键设计决策

### 1. 内核严肃，外壳科普
内核（算法层）严格按古籍规则确定性计算，工程上可验证；外壳（前端）用科普折叠层讲清楚「源流 / 流派分歧 / 诚实边界」，**绝不把娱乐包装成预测**。

### 2. 决策轴模型（本项目最值钱的建模思路）
八大体系术语体系完全不同（五行生克 / 星辰宫位 / 卦象 / 牌意），无法直接相加。玄览把每个体系的「答案」投影到**六条统一的决策轴**上：

| 轴 | 含义 |
| --- | --- |
| 行动 | 宜动 / 宜静 |
| 时机 | 宜进 / 宜守 |
| 人际 | 宜结盟 / 宜独处 |
| 进取 | 宜攻 / 宜稳 |
| 变化 | 宜变 / 宜不变 |
| 吉凶 | 整体倾向 |

每条轴的取值 ∈ [-2, 2]，带该体系的**置信度权重**。聚合层做：
- **加权平均**（置信度加权）→ 各轴主调
- **一致率**（同方向占比）→ 体系们有多齐心
- **分歧体系**（|得分−均值|>1）→ 谁在唱反调

> 这是把「异质多专家系统」收敛到一个可比较空间的标准做法，也是本项目的工程/建模核心。

### 3. 可复现优先
内核纯函数化 + 种子注入，使得「同一问题、同一时刻」永远得到同一结果；历史记录存**完整结果**而非种子，算法演进后老记录也不会变形。

## 功能

- **八顾问合议（招牌视图）**：八大体系化作八位顾问环坐一圈，中央是总体共识环；倾向用色区分（翠绿=动/吉、朱红=静/凶、金=中性），唱反调的体系挂分叉徽标——分歧本身就是信息
- **分歧辩论（最强差异点）**：自动挑出八家分歧最大的一轴，把「主张动/吉」与「主张静/凶」两派各自摊开、附各自判词。AI 会把八家意见揉成一段自信的整合叙事，玄览偏要把分歧演给你看——这才是多专家系统存在的意义
- **共识度仪表盘（圆环 + 一致率色条）**：顶部 SVG 总体共识圆环，六条决策轴各配「方向仪表 + 一致率色条」，相关主题轴高亮，分歧最大的轴单独点名并引导到分歧视图
- **主题化阅读路径**：根据所选主题（事业/感情/财运/搬迁/学业/健康/人际）给出「优先看哪几套体系、重点读哪条轴」的引导，点击芯片直接滚动到对应卡片
- **合议卡分享 + 只读链接**：结果一键生成分享卡（PNG 导出，1080×1440 社交规格）；只读链接只携带「生辰 + 所问 + 起卦种子」，对方打开后由同一内核**确定性重算、逐字一致**，无需任何后端
- **两步引导输入**：先问生辰、再问所问之事，首次使用零门槛；支持公历/农历、真太阳时、时辰未知等细节
- **八大体系并排推演**：八字 · 紫微 · 奇门 · 大六壬 · 小六壬 · 梅花易数 · 西洋占星 · 塔罗（含各自流派开关：奇门置闰/拆补、紫微中州派、塔罗牌阵等）
- **新手引导层**：首访分步引导（产品是什么 / 怎么用 / 共识≠预测 / 数据只在本地），可随时从导航「引导」重看
- **合规与隐私**：首次进入必须点「我已了解」才可使用（使用须知弹层）；隐私与数据说明弹层讲清「纯前端、数据只在你浏览器、不上传」；页脚常驻入口
- **综合解读报告**：把八家结论翻译成人话长文，零 AI、零随机，模板化叙事可审计
- **术语词典（38 条）**：卡片内硬核词点击看白话解释；导航「术语」打开可搜索总览（用神/大运/牌阵/分宫制…）
- **历史记录 + 导出/导入**：排盘自动入库，支持搜索、主题筛选、收藏星标、回放、导出 Markdown/JSON、一键导出全部备份、导入备份（去重合并）、单条/清空删除
- **多端适配 + 无障碍**：手机 / 平板 / 桌面三档断点全覆盖，导航吸顶；弹层支持 Esc 关闭、Tab 焦点陷阱、可见焦点环，符合 WCAG 2.1 AA 基本盘
- **错误边界兜底**：任一体系渲染异常只局部降级「该体系暂不可用」，不整页白屏
- **可安装 / 可离线（PWA）**：Service Worker 让全站（含 1.2MB 算法内核）离线可用、可添加到主屏——兑现「全本地、零服务器、隐私不上传」的核心卖点
- **入场页 + 项目故事页**：仪式感太极八卦入口；项目故事页讲清思考、迭代与能力范围

## 快速开始

```bash
npm install
npm run dev        # 本地开发，默认 http://localhost:5173
npm run build      # 生产构建
npm test           # 内核测试（42 项：黄金样本 / 对拍 / 边界 / 决策轴 / 确定性回放）
npm run test:ui    # 前端组件测试（Vitest + Testing Library）
npm run typecheck  # 类型检查（tsc --noEmit）
```

> 测试依赖 Node 22+（内核用原生 type stripping 直跑 .ts，无 tsx/ts-node）。
> 当前测试覆盖：**内核 42 项 + 前端 24 项 = 66 项**。CI（` .github/workflows/ci.yml`）在每次 push / PR 跑 typecheck + build + 两套测试。

## 架构

```
packages/core/            纯函数算法内核（禁 IO / 禁 Date.now / 禁 Math.random）
  ├─ adapters/            八大体系适配层（mingyu-core + iztro）
  ├─ interpretation.ts    确定性解释层（五行旺衰 / 体用生克 / 吉凶 / 应期…，六轴全覆盖）
  ├─ consensus.ts         决策轴聚合（加权平均 + 一致率 + 分歧）
  ├─ report.ts            综合解读报告（模板化叙事，零随机、零 AI）
  └─ test/                内核回归测试（42 项，含 golden 对拍 / 端到端确定性回放）
src/
  ├─ features/
  │   ├─ form/            两步引导表单（生辰 → 所问之事）
  │   └─ results/         共识仪表盘 + 综合报告 + 八体系结果墙
  ├─ Landing.tsx          太极八卦入场页（价值主张：为何不用直接问 AI）
  ├─ AdvisoryCouncil.tsx  八顾问合议英雄视图（SVG 环形议事）
  ├─ ShareCard.tsx        合议卡弹窗（只读链接 + Canvas PNG 导出）
  ├─ share.ts             分享编解码（base64url 输入包，接收方确定性重算）
  ├─ App.tsx              顶层状态、只读回放路由（#/r=）
  ├─ ConsensusDashboard   六轴共识度可视化
  ├─ SynthesisReport      确定性综合解读
  ├─ CaseStudy.tsx        项目故事页
  ├─ HistoryPanel.tsx     历史记录管理
  └─ renderers.tsx        八体系专属渲染器
```

数据流：`出生信息 + 问题 → 内核并行计算 → 各体系 assertions 投影到决策轴 → 共识聚合 → 八顾问合议视图 / 综合报告 / 各卡解读`。
分享流：`结果 → 输入包 base64url 进 URL hash → 对方浏览器同内核同种子重算 → 逐字一致回放`。

## 主意：

- 以上为各体系按古籍规则的**确定性计算**，不是概率预测，其有效性在科学上尚无共识。
- **命盘类**（八字、紫微、西洋占星）反映长期趋势，由出生信息决定，不随你此刻的问题改变。
- **卜卦类**（六壬、奇门、梅花、小六壬、塔罗）针对你此问的当下信号——换时间 / 换问题，卦象自然不同。
- 涉及人生、医疗、法律、财务的决定，请咨询持证专业人士。

### 隐私与数据

- 本产品**没有后端服务器**，全部为纯前端单页应用（PWA）。
- 你填写的生辰、问题与所有推演结果**仅保存在当前浏览器的 localStorage**，不上传、不收集、不用于任何训练或商业分析。
- 你可以随时在历史记录中单条删除、清空，或一键导出全部数据后自行清理浏览器存储。

### 第三方依赖与许可证归属

- 排盘与历法能力依托开源库 **iztro**（紫微 / 西洋占星，MIT）与 **mingyu-core**（八字 / 奇门 / 六壬 / 塔罗 / 梅花核心算法）；作者并非将这些第三方基础算法包装为「全部自研」，仅在其之上补充了多体系聚合、决策轴建模、共识/分歧聚合、解释层与可复现分享等原创工程。
- 内核测试对拍使用 **lunar-typescript** 与 **liuren-ts-lib**（均仅 devDependency，不进入产物）。
- 各库许可证以其官方仓库为准；本项目本身以 **AGPL-3.0** 开源（见 `LICENSE`）。
